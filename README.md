# ProjectCommand releases

Desktop builds of ProjectCommand, IFC-native project management for heavy civil construction, for Windows and macOS.

## Download 0.8.0

| You have | Download | |
|---|---|---|
| Windows | [ProjectCommand-0.8.0-Windows-Setup.exe](https://github.com/BrandonLewis/projectcommand-releases/releases/download/v0.8.0/ProjectCommand-0.8.0-Windows-Setup.exe) | Installs for you alone, without admin, and keeps itself up to date. |
| Windows, nothing installed | [ProjectCommand-0.8.0-Windows-Portable.exe](https://github.com/BrandonLewis/projectcommand-releases/releases/download/v0.8.0/ProjectCommand-0.8.0-Windows-Portable.exe) | Runs as it is, from wherever you keep it. |
| Mac, Apple silicon or Intel | [ProjectCommand-0.8.0-macOS.dmg](https://github.com/BrandonLewis/projectcommand-releases/releases/download/v0.8.0/ProjectCommand-0.8.0-macOS.dmg) | Open it and drag the app to Applications. |

Earlier versions are under [Releases](../../releases).

An installed copy looks here for a newer version when it starts, and from Help > Check for updates.

The builds are not code signed yet. On Windows choose More info, then Run anyway; on macOS right-click the app and choose Open the first time.

This repository holds releases only. The source is not public.
